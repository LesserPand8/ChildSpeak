# ChildSpeak - きょうの英語（赤ちゃんに話しかける1日1単語）

赤ちゃんに話しかけたい英語フレーズを、1日1つ届けるシンプルなWebアプリです。
ビルド不要の静的サイト（HTML/CSS/JS）なので、そのまま開くだけで動きます。

## 機能

- 日付ごとに自動で今日のフレーズが決まる（`words.js` を順番にローテーション）
- 英文をクリック（タップ）すると音声で読み上げ（Web Speech API）
- 日本語訳を併記

## 使い方（ローカルで確認する）

ブラウザの制限でファイルを直接開くだけでも動きますが、簡易サーバーで開くのが確実です。

```bash
python3 -m http.server 8000
# ブラウザで http://localhost:8000 を開く
```

## 公開する（無料でOK）

静的ファイルだけなので、GitHub Pages / Netlify / Vercel などにそのままアップロードすれば公開できます。

## 単語を増やす・編集する

`words.js` の配列に `{ en, ja, emoji, tag }` の形で追加するだけです。並び順が日替わりのローテーション順になります。

## 今後スマホアプリ化する場合

このWeb版はそのままの見た目・ロジックを流用しやすい構成にしてあります。次のステップとしては：

- **PWA化**（`manifest.json` + Service Worker追加）→ ホーム画面に追加できるように
- **Capacitor** でこのHTML/CSS/JSをiOS/Androidアプリにラップ
- もしくは React Native などでネイティブ実装し直し、`words.js` のデータ構造だけ移植
